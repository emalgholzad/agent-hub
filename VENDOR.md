# Vendor skills

Skills from other authors. They are **not copied** into this repo. A project
references the upstream repo directly, pinned to a commit, so you choose
exactly which ones to use and `apm outdated` shows when upstream moves.

Copy the lines you want into `dependencies.apm` in a project's `apm.yml`.
The commit pins below were taken on 2026-11-08; bump them when you review upstream.

Not listed: `mattpocock/skills` `resolving-merge-conflicts`, which upstream removed as a skill (it is now only a doc).
